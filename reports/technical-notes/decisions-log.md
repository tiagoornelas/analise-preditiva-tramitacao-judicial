# Methodological decisions log

## Current decisions

1. The study prioritizes adherence to the real CNJ data available over strict literal adherence to the pre-project wording.
2. The project uses `tpbaixc1m` as the main target because it is the strongest available proxy for first-degree average case duration in the filtered sample.
3. The project uses `procel1` as the main digitalization variable.
4. The main analytical sample is limited to tribunal-year observations from 2015 to 2023 in `Estadual`, `Federal`, and `Trabalho`.
5. Aggregate rows `TJ`, `TRF`, and `TRT` are excluded to avoid mixing institutional totals with tribunal-level observations.
